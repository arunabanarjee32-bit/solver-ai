1. Logical ownership was compared before physical moves.
The browser implements interaction, FastAPI enforces API identity and queue
ownership, and a separate gVisor controller executes untrusted programs. Moving
all these into a single folder/process would weaken real runtime boundaries.
The final architecture retains apps/web, services/api and services/judge.

features/accounts contains account UI and browser/server auth adapters;
features/practice contains catalog/editor/workspace and public catalog client;
features/submissions contains submission UI/history and authenticated queue client;
features/hints contains recovered account-hint UI and validated hint client.
Next app-router routes remain in app/. Shared shell/icons remain in components/.
Auth tests/migrations and browser resilience imports now use their new modules.
Module moves preserve the web process working directory and private data paths.
Every old/new path is listed in ORIGINAL_TO_NEW_PATH_MAPPING.txt.
