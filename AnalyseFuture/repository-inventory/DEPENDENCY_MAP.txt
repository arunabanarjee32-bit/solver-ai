SOLVER AI — RUNTIME AND DEPENDENCY MAP

Browser -> Next.js routes/shared shell -> feature-owned components and clients.
accounts/client wraps Better Auth browser sessions and short-lived JWT requests;
accounts/server configures official Better Auth migrations, private SQLite state
and EdDSA JWKS. The API auth route initializes it lazily. Auth tests import that
same module, not a parallel schema implementation.

practice/api uses Zod to validate public catalog data. Monaco React/monaco-editor
are bundled by copy-monaco.mjs so normal editor startup has no editor CDN/model
request. Practice workspace calls submissions and optional account-hints features.
submissions/api and hints/api obtain short-lived JWTs through accounts/client.
The server-side Next rewrite sends /api/v1/* to configured FastAPI upstream.

FastAPI main composes public catalog, errors/body limits, auth/JWKS, hints and
submission endpoints. Auth verifies configured issuer/audience/EdDSA keys through
HTTPX/PyJWT/cryptography. catalog/models define original public problem data.
hints.py exposes an authored backend and bounded future-provider protocol.
submissions.py owns SQLite persistence, user ownership, idempotency, quotas,
worker readiness and leased completion; no learner code execution occurs here.

Trusted judge worker -> authenticated internal queue/control endpoints -> runner.
runner uses local Docker with gVisor only, verifies image identity/runtime and
passes source/inputs (not expected answers) to bounded sandbox harness. cases.py
and expected answers remain in trusted control. bounded.py enforces subprocess
output/deadline/process-group behavior; harness enforces language/process/temp
limits. Worker normalizes completion independently. This separation is purposeful.

Local scripts select/generate the private worker token and start owned process
groups. Compose runs web/API containers only; application containers have no
Docker socket. Native optional control worker is separate. Root .dockerignore,
Next tracing and standalone guard exclude all AnalyseFuture contents.
